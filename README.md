# Fourfold public information pages

Static homepage, privacy policy, and terms for the owner-operated Fourfold Google OAuth consent screen. No app code, credentials, or owner database data belongs in this repository.

Production domain: `https://fourfold.azpestshield.com/`. The domain must resolve and pass HTTPS checks before it is entered into Google Auth Platform. The corresponding Google OAuth project should be dedicated to Fourfold so changes to its branding and audience do not affect the unrelated CarPartsRadar Supabase client.

The policy is based on the Fourfold code as of September 24, 2026. Update it before changing what Google data the app reads, sends, or retains.
